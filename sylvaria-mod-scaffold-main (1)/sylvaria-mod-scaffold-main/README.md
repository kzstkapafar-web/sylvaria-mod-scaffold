# Sylvaria

Мод для **Minecraft Forge 1.21.1**. Добавляет магическое лесное измерение
Sylvaria, в которое можно попасть через древний портал, поросший
светящимся мхом.

## Статус

- ✅ Измерение Sylvaria (плоский мир, свой биом "sylvaria_forest").
- ✅ Портал: `sylvaria:portal_frame` (декоративная рамка) +
  `sylvaria:sylvaria_portal` (сам портал — заходишь и телепортируешься).
  Портал не требует розжига кремнём и огнивом — работает сразу после
  установки, в обе стороны (туда и обратно).
- ⬜ Дальше по плану: уникальные блоки/растения/мобы измерения,
  полноценная генерация ландшафта вместо плоского мира.

## Как попасть в Sylvaria

1. Получи блок портала: `/give @s sylvaria:sylvaria_portal`
2. (опционально, для красоты) Получи рамку: `/give @s sylvaria:portal_frame`
   и выложи её прямоугольником вокруг места, где поставишь портал.
3. Поставь `sylvaria_portal` и зайди в него — телепортирует в Sylvaria.
4. Чтобы вернуться — зайди в портал, который автоматически появится
   на месте твоего приземления в Sylvaria.

## Сборка

Через GitHub Actions: вкладка **Actions** → workflow **Build Mod** →
**Run workflow** (собирается вручную по кнопке, не на каждый push).
Готовый `.jar` появится в артефактах сборки.
