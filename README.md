# Sylvaria

Мод для **Minecraft Forge 1.21.1**. Добавляет магическое лесное измерение
Sylvaria, в которое можно попасть через древний портал, поросший
светящимся мхом.

## Статус

Каркас проекта — мод пока ничего не делает, кроме как загружается.
Дальше по плану:

- Биом "Зачарованный лес" (уникальный цвет травы/листвы, растительность).
- Само измерение (тип измерения + генератор мира на основе биома).
- Портал (блок рамки + блок портала с телепортацией, по аналогии
  с порталом в Нижний мир).
- Уникальные блоки/растения/мобы измерения.

## Сборка

Через GitHub Actions: вкладка **Actions** → workflow **Build Mod** →
**Run workflow** (собирается вручную по кнопке, не на каждый push).
Готовый `.jar` появится в артефактах сборки.

## Версии

- Minecraft: 1.21.1
- Forge: 52.1.14
