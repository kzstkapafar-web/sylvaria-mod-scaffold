# Sylvaria

Мод для **Minecraft Forge 1.21.1**. Добавляет магическое лесное измерение
Sylvaria, в которое можно попасть через древний портал, поросший
светящимся мхом.

## Статус

- ✅ Измерение Sylvaria (полноценная генерация рельефа поверх ландшафта
  оверворлда, зафиксированный биом "sylvaria_forest").
- ✅ Портал: `sylvaria:portal_frame` (рамка, добывается в выживании) +
  `sylvaria:sylvaria_portal` (сам портал, зажигается кремнём и огнивом,
  анимированная текстура). Работает в обе стороны.
- ✅ Автопостроение зеркальной рамки на другой стороне, без наложения
  порталов друг на друга (см. ниже).
- ⬜ Дальше по плану: уникальные блоки/растения/мобы измерения.

## Как попасть в Sylvaria

1. Добудь рамку крафтом (3x3: `cobbled_deepslate` по краям + `amethyst_shard`
   в центре = 4 `sylvaria:portal_frame`), либо `/give @s sylvaria:portal_frame`.
2. Построй из рамки прямоугольный периметр (как портал в Нижний мир,
   но размер гибкий: внутренний проём от 2x2 до 19x19 блоков).
3. Подожги проём кремнём и огнивом, кликнув по любому блоку рамки —
   проём заполнится живым, светящимся порталом `sylvaria_portal`.
4. Зайди внутрь — телепортирует в Sylvaria.

### Что происходит на другой стороне

- Если рядом (в пределах ~32 блоков от соответствующей точки) уже есть
  портал, ведущий сюда же — игрок телепортируется в него, новый портал
  **не строится повторно**.
- Если рядом ничего нет — мод автоматически строит зеркальную рамку
  (той же ширины/высоты/оси, что построил игрок) и сразу её зажигает.
- Место для новой рамки ищется расширяющейся спиралью и всегда
  выбирается так, чтобы не пересекаться с уже существующими порталами
  (с отступом в несколько блоков) — сколько бы порталов ни было
  понастроено в одном районе, они никогда не наложатся друг на друга.
- Сломать рамку в любом мире — портал внутри неё гаснет (превращается
  в воздух).

## Сборка

Через GitHub Actions: вкладка **Actions** → workflow **Build Mod** →
**Run workflow** (собирается вручную по кнопке, не на каждый push).
Готовый `.jar` появится в артефактах сборки.
